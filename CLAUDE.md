# Project instructions

## Commit messages

- Subject line: short and in the imperative mood, for example `Add schema validation tests`, not `Added …` or `Adds …`.
- Body: a brief bulleted list of what changed, one short bullet per change.

Example:

```
Add .gitignore

- Ignore node_modules, npm logs and tool caches
- Ignore .env files, keeping .env.example
- Ignore diagnostics, screenshots and coverage output
```
